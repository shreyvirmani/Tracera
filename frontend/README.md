# Tracera Frontend

Next.js-based frontend for the Tracera website risk assessment platform.

## Requirements

- Node.js 20+
- npm or pnpm

## Setup

```bash
cd frontend
npm install
```

## Development

```bash
# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start

# Lint
npm run lint

# Format
npm run format
```

## Project Structure

```
frontend/
├── app/                 # App Router pages
├── components/          # React components
├── hooks/               # Custom React hooks
├── lib/                 # Utility functions
├── services/            # API services
├── public/              # Static assets
├── styles/              # Global styles
├── types/               # TypeScript types
├── tests/               # Test suite
├── package.json
├── tsconfig.json
└── next.config.ts
```
